# 拾光档案馆

一个纯静态、无需服务器的私人生活记录网站，可直接部署到 GitHub Pages。

## 功能

- 每段记忆可一次选择最多 12 张照片，并自动压缩保存
- 可拖动或用箭头调整照片顺序，把任意照片设为封面
- 记录日期、心情、地点和文字
- 支持旧记录再次整理、沉浸式回忆放映和按月时光日历
- 在浏览器的 IndexedDB 中本地保存
- 支持删除、导出及导入 JSON 备份
- 支持安装到手机或电脑桌面，并离线打开已加载的网站
- 响应式布局，支持手机和电脑

> 隐私提示：记录只保存在当前浏览器，不会同步到 GitHub。清理浏览器数据或更换设备前，请先点击“导出备份”。
